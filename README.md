# PeakFinder (web prototype)

Open on your phone: **https://nightskyfinder-app.github.io/peakfinder/**

A mobile web app that draws the mountain skyline around you and labels the visible peaks.
See [PLAN.md](PLAN.md) for the plan and progress, and [CLAUDE.md](CLAUDE.md) for project rules.

Every push to `main` rebuilds and redeploys the site automatically (see the **Actions** tab).

Peak data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
Elevation: Mapzen Terrarium tiles via [AWS Open Data](https://registry.opendata.aws/terrain-tiles/).
